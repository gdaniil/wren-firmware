## 2. Missing or broken

High:
- Battery % toggle in setup writes `hideBatteryPercentage`; Wren status lines always draw `NN%` (`WrenChrome.cpp:171-201`, checked).
- Hotspot SSID changed from `CrossPoint-Reader` to open `wren-xxxx` (`WrenSendActivity.cpp:143-147`, checked). Documented in
  `docs/webserver-endpoints.md:550`. HTTP API unchanged, but apps that join by SSID will not find it. Needs the smoke test.
- Wren reader fonts need `.cpfont` files on the SD card; they exist only in `build/wren-fonts/`, and nothing delivers them.
  Without them the font/size rows change nothing visible.

Status 15 Nov: battery fixed (`WrenChrome.cpp`: menus hide the number for "always", the reader for "in reader" and
"always"). Fonts: `scripts/wren/install_fonts.py --sd|--device`. SSID kept as `wren-xxxx` (Daniil), noted in REPO_MAP.

Medium:
- Orientation toggle is portrait/landscape only (`ReaderMenuState.h:7`, checked); inverted and CCW unreachable on device.
- Sleep screen and sleep-after rows show blank for saved values outside the Wren options and overwrite them on first press
  (`SetupState.h:13-21`, checked).
- Dead settings: `statusBar*`, long-press menu choice, margins, line spacing, hyphenation, embedded style are editable only via web.
- OPDS unreachable (no callers of `goToBrowser`).
- Tabs on Setup, Send, Wi-Fi, system screens, delete dialog pass `physicalEdge=false`: in landscape they may not sit above the buttons (unverified).
- Touch boards keep the upstream toolbar menu (unverified).

Low: files has delete only (no rename/folders); language cycles en/ru/uk only; crash screen lost its "no reason" fallback;
unused keys `STR_WREN_BUSY_PAGE_SAVED`, `_OPENING`, `_BOOKS_FOUND`, `STR_THEME_WREN`, `STR_WREN_SETUP_DARK`;
32 other languages show English on Wren screens.

## 3. Size

`default`: flash 5,799,049 / 6,553,600 B (88.5%), static RAM 66,664 B.

| Area | Flash |
|---|---|
| Built-in fonts (Noto 12-18 x4 styles ~820 KB, Ubuntu 8-12 ~260 KB, Wren Golos/mono ~200 KB) | ~1.3 MB |
| i18n, 34 languages | up to ~440 KB (broad match) |
| Hyphenation tries (de alone 201 KB) | ~350 KB |
| Bluetooth / NimBLE | ~230 KB |
| Web page assets (jszip 28 KB) | ~80 KB |
| OPDS | ~68 KB |
| Themes RoundedRaff + Lyra3Covers + CoverGrid | ~4 KB |

UI languages trimmed to en+uk on 15 Nov (`custom_i18n_builtin_langs = uk` in platformio.ini): i18n tables 439 -> 36 KB.

Removing themes saves almost nothing. Real wins: Noto reader fonts once Wren SD fonts are the reader fonts
(but they are the fallback today), hyphenation and UI languages we do not ship, Bluetooth if we drop page turners.
Static RAM is barely affected by any of these (flash data).

Safe removals (Codex): dead `HomeActivity` + `CoverGridHomeUi`, three dead `EpubReader*Activity` screens.
Themes: keep enum slots 0-4 for `/api/settings`, map all to Wren, hide the picker.
