# Original table-mode mismatch reference

Historical T1 results, before fixing the crossbar sampling error. These 44 rows are retained verbatim for comparison and are not current measurements. In particular, Golos 9 bold and Bitter 9 bold were crossbar widths, not stem widths.

Stem = median width of the leftmost ink run in the upper/lower middle bands (25–40% and 60–75% of bitmap height), excluding crossbar and serifs. Targets use round-half-up. Lightest weight scans every integer wght across the source axis at the chosen style em/opsz, holding em fixed; “none” means that exact stem width is unattainable. The prescribed weight table is never changed.
